# 🎓 Student Management System

A simple Student Management System built using HTML, CSS, and JavaScript.

This project allows users to add, view, delete, and restore student records. Data is stored using the browser's Local Storage, so student information remains available even after refreshing the page.

---
## 📌 Features

### ✅ Add Student
- Enter student details:
  - Name
  - Roll Number
  - Department
  - Year
- Store student information dynamically.

### ✅ View Students
- Display all current students.
- Show student details in a structured format.

### ✅ Delete Student
- Remove students from the active list.
- Confirmation popup before deletion.

### ✅ Removed Students History
- Deleted students are not lost.
- Stored in a separate "Removed Students" section.

### ✅ Restore Student
- Restore deleted students back to the active list.

### ✅ Local Storage
- Student data remains available after page refresh.
- No database required.
